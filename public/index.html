How to Search

The Browser Tab allows you to search the local MITRE database. If a record is not found locally, the system will automatically attempt to fetch it from NIST NVD or OSV.dev.

  • Search by ID: CVE-2024-1234
  • Search by Keyword: SQL Injection
  • Search by Product: Oracle WebLogic
2

Threat Overview

The Threats Tab generates real-time analytics based on your search criteria. It aggregates CVSS scores, estimates exploitation risks, and identifies common weaknesses (CWEs).

Supported Vendors (Examples)

Microsoft Oracle SAP Cisco Adobe IBM Apache VMware
3

File Loader Instructions

You can upload vulnerability scan reports or asset lists. The system scans the file content for any text matching the CVE-YYYY-NNNN pattern.

CVE-2024-5678
